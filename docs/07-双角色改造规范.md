# 双角色改造规范 (kid / parent)

> 版本：v1.0 · 日期：2026-11-01 · 作者：Mavis (设计主导)
> 配套：`docs/02-页面设计.md`（旧版家长视角，已被本文档取代）、`docs/01-功能设计.md`
> 本文是**前端 CSS / JS 与后端实现共同遵循的契约**。类名、接口、字段名一律以此为准。

---

## 0. 一句话方向

> **同一本作业本，两种读法。**

孩子读的是**方格本 + 星星罐**：一张纸，一格一格往前爬，攒下来的星星装进罐子。
家长读的是**备课本 + 批改台**：一行一行对账，看的是效率与结论。

两端是**同一份数据**、**同一套颜色编码**，但纸不一样、信息密度不一样、能做的操作不一样。

## 1. 角色模型

### 1.1 角色状态

- `document.documentElement.dataset.role` = `"kid"` | `"parent"`
- 持久化：`localStorage["st.role"]`，默认 `"parent"`
- 切换控件：header 右上角 `.role-switch`

### 1.2 家长端 PIN 门槛

| 情况 | 行为 |
|---|---|
| 家长 → 孩子 | 直接切，无需验证 |
| 孩子 → 家长，且已设 PIN | 弹 `.pin-gate`，输对才放行 |
| 孩子 → 家长，且未设 PIN | 弹 `.pin-gate`，提示"首次使用，请先设置 4 位密码"，设置完直接进入 |
| 连续输错 3 次 | 提示"密码错了 N 次"，锁 60 秒（前端计时，不持久化） |

PIN 存后端（PBKDF2 哈希），**前端不存明文 PIN**，只有"是否已设置"走本地标记。

### 1.3 导航

两个角色都是 **3 个 Tab**，但内容不同。

| Tab | 家长端 | 孩子端 |
|---|---|---|
| 今日 | 批改台（数据卡 + 批量操作 + 密集任务行） | 星星罐 + 大任务卡 |
| 日历 | 热力图 + 悬停详情卡 | 贴纸册 |
| 复盘 | 周期复盘（环形图 / 折线 / 薄弱项） | 我的成绩单（勋章墙 + 成长报告） |

**家长端专属页**（不在 Tab 里，从页面内进入）：

| 页面 | 入口 | hash |
|---|---|---|
| 登记作业 | 今日页右上「＋ 登记作业」按钮 | `#/entry` |
| 周计划 | 日历页右上「周计划」按钮 | `#/week` |
| 设置 | header 右上角头像菜单 | `#/settings` |

孩子端**看不到**登记 / 周计划 / 设置的入口。

### 1.4 路由

沿用现有 hash 路由与 `switchTab()`，新增：

- `#/settings` 已存在
- Tab 键名不变：`board` / `list` / `review`
- 孩子端切到 `entry` / `week` / `settings` 时**回退到 `board`**，不报错

## 2. 色彩系统

### 2.1 共用编码（两个角色完全一致，贯穿看板 / 日历 / 复盘）

每个颜色给两个值：`-c` 主色（文字 / 描边 / 实底）、`-t` 浅底（chip 背景）。
主色对白底对比度均 ≥ 4.5:1。

| 类别 | 主色 | 浅底 | 用法 |
|---|---|---|---|
| 语文 | `--s-yu-c: #BF3B2E` | `--s-yu-t: #FBEAE6` | 科目 chip / 左色条 / 图表 |
| 数学 | `--s-shu-c: #2C6BA8` | `--s-shu-t: #E7F0F8` | 同上 |
| 英语 | `--s-ying-c: #5A8F1E` | `--s-ying-t: #F0F5E4` | 同上 |
| 培训 | `--s-pei-c: #6B4C9A` | `--s-pei-t: #EEEAF6` | 任务来源 |
| 习惯 | `--s-xi-c: #1F7368` | `--s-xi-t: #E4F1EF` | 任务来源 |

**状态色**（形状 + 颜色双信号，禁止只靠颜色）：

| 状态 | 主色 | 浅底 | 形状信号 |
|---|---|---|---|
| 待做 | `--st-todo-c: #6E6459` | `--st-todo-t: #F0EDE8` | 空心圆点 |
| 进行中 | `--st-doing-c: #C77700` | `--st-doing-t: #FBF0DC` | 实心圆 + 进度条 |

## 3. 字体

| 角色 | 用途 | 字体 | 回退栈 |
|---|---|---|---|
| 孩子端 | 标题 / 任务名 | LXGW WenKai TC（霞鹜文楷，楷体） | `"Kaiti SC", "STKaiti", KaiTi, "楷体", serif` |
| 家长端 | 标题 | Noto Serif SC（思源宋体） | `"Songti SC", SimSun, "宋体", serif` |
| 两端 | 正文 / UI | 系统黑体 | `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` |
| 两端 | **所有数字** | 系统黑体 + `tabular-nums` | 不用衬线/楷体渲染数字，保证竖列对齐 |

加载（`index.html` 的 `<head>`）：

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=LXGW+WenKai+TC:wght@400;700&family=Noto+Serif+SC:wght@500;700&display=swap" rel="stylesheet">
```

离线时走回退栈：Windows 自带楷体 / 宋体，角色区分仍然成立。**不得**因为字体加载失败而阻塞渲染（`display=swap`）。

## 4. 组件规范

### 4.1 孩子端 · 星星罐（签名组件）

```html
<div class="kid-hero">
  <div class="jar" aria-hidden="true">
    <svg viewBox="0 0 120 140">…玻璃罐 + 星星…</svg>
    <div class="jar-fill" style="--stars: 3"></div>
  </div>
  <div class="kid-hero__text">
    <p class="kid-hero__line">还差 <b>2</b> 项就全部完成啦</p>
    <p class="kid-hero__sub">今天拿到 <b>3</b> 颗星 · 罐里有 <b>18</b> 颗</p>
  </div>
</div>
```

- 罐子高度随 `--stars` 填充比例变化（`--stars / --jar-cap`，容量 20 颗封顶后显示溢出数）
- 每颗星是五角星 path，从罐底往上堆，最多可见 9 颗（超出用 `+N` 角标）
- 星星三色随机取 `--star` / `--star-2` / `--star-3`，但**位置固定**（用 id 派生种子，不用 `Math.random`，避免重绘时星星乱跳）
- 全部完成时罐子加 `.is-full` class，出现溢出的星星 + 庆祝层

### 4.2 孩子端 · 任务卡

```
┌─────────────────────────────────────┐
│ ▎语文              约 20 分钟  ⋯   │   ← 左色条 + 学科 + 预计 + 更多
│   完成知能 P14                       │   ← 任务名，楷体
│   ┌───────────────┐                  │
│   │    完 成      │                  │   ← 唯一主按钮，48px 高
│   └───────────────┘                  │
└─────────────────────────────────────┘
```

- 卡片圆角 20px，底 `--paper-2`，描边 `--rule`
- 孩子端**只保留**「完成」一个大按钮；编辑 / 今天不做 / 删除 全部收进右上角 `⋯` 菜单
- 「完成」是蜡笔黄填充 + 深墨字，按下时轻微下沉（`transform: translateY(1px)`）
- 完成后卡片变成「已完成」态：左侧色条变绿、卡片降饱和、显示「完成啦 ✓」

### 4.3 孩子端 · 贴纸册日历

```
     一    二    三    四    五    六    日
   ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐
   │ 27 ││ 28 ││ 29 ││ 30 ││ 31 ││  1 ││  2 │
   │ ☆  ││ ★  ││ ★  ││ ☆  ││ ★  ││    ││    │
   └────┘└────┘└────┘└────┘└────┘└────┘└────┘
```

- 每格是一张"贴纸位"：全完成 → 一枚学科色星形贴纸；部分完成 → 半张贴纸；无作业 → 留白
- 今天的格子有一圈手绘感虚线框
- 贴纸用学科主色实底 + 白字小圆点，不用 emoji

### 4.4 孩子端 · 我的成绩单

- 顶部一条本周"成绩单"横幅：大字完成率 + 一句评语（由数据生成，不夸张）
- 中间：勋章墙 `.medal-wall`，每枚勋章 72×72 圆角方章，未获得是浅色轮廓 + 锁
- 底部：本周获得的星星明细

### 4.5 家长端 · 批改台

```
┌──────────────────────────────────────────┐
│ 完成率        剩余用时       学科分布      │  ← 3 张数据卡
│  67%           38 分        ▰▰▱           │
│ 4/6 项        还要写多久   语 60% 数 40%   │
└──────────────────────────────────────────┘
┌──────────────────────────────────────────┐
│ ☐ 全选   已选 3 项   [设为选做][改期][删除]│  ← 批量条，选中才出现
├──────────────────────────────────────────┤
│ ☐ ▎语文  完成知能P14          20分  待做 ⋯│
│ ☐ ▎数学  口算练习 20 道       15分  待做 ⋯│
└──────────────────────────────────────────┘
```

- 数据卡：`.p-stat` / `.p-stat__num` / `.p-stat__label` / `.p-stat__hint`
- 任务行：`.p-row`，勾选框在左，行内右对齐分钟数与状态
- 批量条：`.p-batch-bar`，固定在任务区顶部，出现时用 160ms 下滑入
- 「删除」在批量条里是危险样式（红色描边），确认后才执行

### 4.6 家长端 · 复盘可视化

- **环形占比图**：科目用时占比，SVG `stroke-dasharray` 画环，中心显示总分钟数
- **每日用时折线**：7 个点，异常高点（超过中位数 1.5 倍）标红并给出原因说明
- **薄弱项卡**：从 `daily_reflections.tags` 聚合出"本周数学错题整理耗时最长"这类结论
- **未完成任务**：每条右侧一个「挪到下周」按钮，一键改 `due_date` 到下周一

### 4.7 晚间小结（家长端专用，轻量化）

- 难度 / 专注 / 情绪 → **大色块按钮**（不是小 chip），选中态实心填充 + 对勾
- 文字备注 → 改成**标签快选**（点选即用，多选）：
  `写字慢` `读题走神` `错题多` `内容不熟` `速度正好` `很专心`
- 「保存」按钮固定在模块底部，永远可见可点
- 标签通过 `daily_reflections.tags` 落库（新增列，见 §5.3）

## 5. 后端契约

### 5.1 迁移 v5（`app/migrations/steps.py`）

新增 4 张表 + 1 列，全部带 `family_id` / `child_id` 外键：

```sql
-- 星星账本: 正数 = 获得, 负数 = 消耗
CREATE TABLE IF NOT EXISTS kid_star_ledger (
    id            BIGSERIAL PRIMARY KEY,
    family_id     BIGINT NOT NULL REFERENCES families(id) ON DELETE CASCADE,
    child_id      BIGINT NOT NULL REFERENCES children(id) ON DELETE CASCADE,
    star_date     DATE NOT NULL,
    stars         INTEGER NOT NULL,
    reason        TEXT NOT NULL,
    assignment_id BIGINT REFERENCES assignments(id) ON DELETE SET NULL,
    created_at    TIMESTAMPTZ NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_star_ledger_family_date
    ON kid_star_ledger(family_id, star_date);
-- 同一条作业只能发一次星, 防止重复 PATCH 叠发
CREATE UNIQUE INDEX IF NOT EXISTS idx_star_ledger_assignment_once
    ON kid_star_ledger(assignment_id) WHERE assignment_id IS NOT NULL;

-- 勋章: 同一种勋章只记一次
CREATE TABLE IF NOT EXISTS kid_medals (
    id          BIGSERIAL PRIMARY KEY,
    family_id   BIGINT NOT NULL REFERENCES families(id) ON DELETE CASCADE,
    child_id    BIGINT NOT NULL REFERENCES children(id) ON DELETE CASCADE,
    medal_key   TEXT NOT NULL,
    earned_date DATE NOT NULL,
    meta        TEXT,
    created_at  TIMESTAMPTZ NOT NULL,
    UNIQUE (family_id, child_id, medal_key)
);

-- 连续天数: 一天一行
CREATE TABLE IF NOT EXISTS kid_streaks (
    id             BIGSERIAL PRIMARY KEY,
    family_id      BIGINT NOT NULL REFERENCES families(id) ON DELETE CASCADE,
    child_id       BIGINT NOT NULL REFERENCES children(id) ON DELETE CASCADE,
    streak_date    DATE NOT NULL,
    current_streak INTEGER NOT NULL DEFAULT 0,
    best_streak    INTEGER NOT NULL DEFAULT 0,
    stars_earned    INTEGER NOT NULL DEFAULT 0,
    tasks_done     INTEGER NOT NULL DEFAULT 0,
    updated_at     TIMESTAMPTZ NOT NULL,
    UNIQUE (family_id, child_id, streak_date)
);

-- 家长 PIN: 只存 PBKDF2 哈希, 不存明文
CREATE TABLE IF NOT EXISTS parent_access (
    id         BIGSERIAL PRIMARY KEY,
    family_id  BIGINT NOT NULL REFERENCES families(id) ON DELETE CASCADE,
    pin_hash   TEXT NOT NULL,
    created_at TIMESTAMPTZ NOT NULL,
    updated_at TIMESTAMPTZ NOT NULL,
    UNIQUE (family_id)
);

-- 晚间小结加标签列 (多标签, 逗号分隔的 code)
ALTER TABLE daily_reflections ADD COLUMN IF NOT EXISTS tags TEXT;
```

### 5.3 自动发星 / 撤销

在 `assignment_service.update_status()` 与 `update_completion()` 里挂钩：

| 事件 | 星星 | reason |
|---|---|---|
| 状态 → `done`（必做 / 选做 / 训练 / 习惯都算） | +1 | `earn_task` |
| 状态从 `done` 退回其他 | −1（撤销该 assignment 的星） | `revoke_task` |
| 当天全部必做完成 | +3 | `bonus_all_done` |
| 家长手动奖励 | 任意正数 | `bonus_manual` |
| 家长手动扣除 | 负数 | `spend` |

**幂等**：`idx_star_ledger_assignment_once` 保证同一条作业只发一次星；
撤销时按 `assignment_id` 删掉那一行。

### 5.4 连续天数

当天全部必做完成 → `kid_streaks` 当日行 `current_streak = 上一条 + 1`，
`best_streak = max(best, current)`。当天没全部完成 → 当日行 `current_streak = 0`。

### 5.5 勋章规则

在 `GET /api/kid/medals` 调用时评估，命中就写 `kid_medals`（幂等，UNIQUE 约束兜底）。

| key | 名称 | 条件 |
|---|---|---|
| `first_star` | 启程星 | 累计获得第 1 颗星 |
| `streak_3` | 连续三天 | 连续完成 3 天 |
| `streak_7` | 坚持一周 | 连续完成 7 天 |
| `full_week` | 完美一周 | 一周 7 天全部完成必做 |
| `speedster` | 效率小达人 | 一周完成 ≥5 项，实际用时比预估少 ≥20% |
| `focused` | 专心小蜜蜂 | 一周小结专注度全为 `good`（≥3 条） |
| `tag_master` | 错题克星 | 一周小结里 `many_errors` 标签 ≤1 次且完成率 ≥80% |

勋章条目要有 `name` / `desc` / `icon`（图标用**内联 SVG path 名**，不是 emoji）。

### 5.6 晚间小结标签

`daily_reflections.tags` 存 code，逗号分隔。允许的 code：

```
slow_writing  写字慢      reread      读题走神
many_errors   错题多      unfamiliar  内容不熟
good_pace     速度正好    focused     很专心
```

`POST /api/daily-wrap` 与 `GET /api/daily-wrap` 的 DTO 增加 `tags: list[str]`。

### 6.1 孩子端词表（禁止出现成人术语）

## 7. 交互细则

### 7.1 完成反馈

| 场景 | 反馈 |
|---|---|
| 单项完成（孩子端） | 星星从卡片飞进罐子（260ms，`transform` + `opacity`），卡片翻成「完成啦 ✓」 |
| 单项完成（家长端） | 行内变绿 + 对勾，无动效 |
| 当天全部完成 | 全屏 `.celebrate` 庆祝层：星星从上方落下 + 「今天全部完成啦！」+ 获得 3 星提示 |
| 撤销完成 | 星星从罐子里退掉，无庆祝 |

`.celebrate` 尊重 `prefers-reduced-motion: reduce` → 关闭落星动画，只留静态文案。

### 7.2 计时器

- 任务卡上的「开始计时」按钮 → 计时中显示 `已计 12:34`，再点一次停止
- 停止后把实际用时（分钟，四舍五入，最少 1）写进 `actual_minutes`
- 计时状态存内存（刷新丢失），不要持久化

### 7.3 批量操作（家长端）

选中 ≥1 条时 `.p-batch-bar` 出现，支持：

| 操作 | 实现 |
|---|---|
| 设为选做 | 循环 `PATCH /api/assignments/{id}/optional {is_optional:true}` |
| 取消选做 | 同上，`false` |
| 改到明天 | 循环 `PATCH /api/assignments/{id} {due_date: 明天}` |
| 删除 | 循环 `DELETE /api/assignments/{id}`，**必须二次确认** |

批量操作全部走**已有接口**，不新增后端端点。

### 7.4 键盘与无障碍

- 所有交互元素键盘可达，`:focus-visible` 有 2px 描边
- 状态不只靠颜色：形状 + 文字双信号
- 触控目标：孩子端 ≥48×48px，家长端 ≥40×40px
- `prefers-reduced-motion: reduce` 下关闭所有动效
- 贴纸 / 勋章的 `<svg>` 必须有 `aria-hidden="true"` + 相邻的 `aria-label` 文字
