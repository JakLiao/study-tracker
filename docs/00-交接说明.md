## 3. 关键事件：曾出现 P0 阻断 Bug（已修复，接手方需知）

码灵首版交付时**自报 67/67 测试全过**，慧文独立真跑一次 MiniMax 调用，直接 500：

```
KeyError: '\n  "subject"'
app/prompts.py:126  SYSTEM_PROMPT.format(today=..., weekday=...)
```

**根因**：`SYSTEM_PROMPT` 字符串内含字面量 JSON 花括号（第 35 行 schema 块、第 56 行示例），
`.format()` 把 `{` 当命名占位符解析，抛 KeyError。

**为什么 67 个测试没抓到**：所有 AI 相关测试都 mock 掉了 `call_minimax`，
`build_messages()` 这条真实路径**一次都没被执行过**。

**修法**：改用 `string.Template`（只识别 `$identifier`，完全忽略 JSON 花括号），
并补了 10 条**不 mock** 的回归测试（`tests/test_prompts_regression.py`）。

> ⚠️ **给接手方的教训**：这个项目「测试全过 ≠ 功能可用」。
> 任何涉及 AI 真实调用的改动，必须真跑一次，不能只信 pytest。
