## 1. 整体基调与设计原则

### 1.1 一句话基调

> **「一份给家长看的家长会备忘录」** —— 不卡通、不儿童化、不游戏化；像一份严谨但不冰冷的工具表。

主理人每天在家长群和备忘录之间反复操作，这个工具的目标是**抢回那 15~30 分钟**。所以视觉语言要传达：
- **可信**：结构清晰、字段可点击核对（不黑盒）
- **克制**：没有冗余装饰、没有渐变光斑
- **密度高**：单屏容纳尽可能多的真实信息（家长眼里的"值"）

### 1.2 五条原则（绝对不能违反）

| # | 原则 | 反例 |
|---|---|---|
| P1 | **家长视角，不是孩子视角** | 不出现卡通形象、糖果色、贴纸、emoji 大头 |
| P2 | **时长是英雄元素** | 预估 / 实际分钟数必须一眼可读，数字要齐 |
| P3 | **置信度必须显眼可辨** | 低置信度不能"温和化"——必须家长能一眼认出 |
| P4 | **所有操作可逆、可追溯** | 每个数据点都能点回 `source_span` 原文 |
| P5 | **空状态 / 失败状态也是产品** | 不能只有"成功"长得好 |

### 1.3 不做什么（明确 non-goals）

- ❌ 任何形式的卡通插画、IP 形象
- ❌ 渐变背景、毛玻璃、霓虹色
- ❌ Emoji 作为视觉装饰（仅作为状态/警示文字前缀）
- ❌ 大色块、特大留白（Awwwards 风不适合工具）
- ❌ 微动效超过 150ms
- ❌ 任何"祝贺你完成作业"式的弹窗

## 2. 配色系统

### 2.1 中性色（85% 屏幕面积）

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `--bg` | `#F5F6F8` | `#0F1419` | 页面底色 |
| `--surface` | `#FFFFFF` | `#1A2027` | 卡片底色 |
| `--surface-2` | `#F0F2F5` | `#222A33` | 次级容器（折叠区、空状态） |
| `--border` | `#E2E5EA` | `#2D3742` | 描边 |
| `--text-1` | `#1F2937` | `#E8ECF1` | 主文字 |
| `--text-2` | `#4B5563` | `#A5B1BD` | 次文字（预估时长、数值） |
| `--text-3` | `#9CA3AF` | `#6B7785` | 弱文字（时间戳、辅助说明） |

**对比度要求**：所有正文文字与底色对比度 ≥ 4.5:1（WCAG AA）。

### 2.2 科目色（10% 屏幕面积，但语义关键）

刻意选择**低饱和 + 等明度**的三色，扫一眼不会刺眼，叠在一起不打架：

| 科目 | 主色（HEX） | 浅底色（HEX） | 选择理由 |
|---|---|---|---|
| **语文** | `#B4502E` 朱磦 | `#FBEFE9` | 偏赭红/朱砂，避开大红色块 |
| **数学** | `#3B6FA5` 靛青 | `#EBF1F7` | 沉稳蓝灰，避开荧光蓝 |
| **英语** | `#5B8A6B` 松烟绿 | `#EFF4F0` | 偏沉静的绿，不抢眼 |

**使用规则**：
- 科目名、左侧 4px 色条、徽章 = 主色
- 卡片背景 = 浅底色（饱和度低）
- 禁止在科目色上叠渐变、阴影

### 2.3 状态色（5% 屏幕面积，最关键的语义信号）

| 状态 | Token | Light | Dark | 视觉 |
|---|---|---|---|---|
| 待做 | `--status-todo` | `#6B7280` | `#9CA3AF` | 灰底深灰字 + 空心圆点 |
| 进行中 | `--status-doing` | `#D97706` | `#F59E0B` | 琥珀色填充 + 旋转指示 |
| 已完成 | `--status-done` | `#059669` | `#34D399` | 青绿勾选 + 删除线 |
| 选做 | `--status-optional` | `#9CA3AF` | `#6B7785` | 灰底 + 「选」字徽章 |
| 已逾期 | `--status-overdue` | `#DC2626` | `#F87171` | 暗红边条 + 抖动提示 |

**关键规则**：「进行中」是**唯一**会用实心填充 + 强提示的状态（家长最关心的就是"现在进行到哪了"）。

### 2.4 警示 / 置信度色

| 用途 | Light | Dark | 出现位置 |
|---|---|---|---|
| 高置信度 | 不加装饰 | — | 默认行 |
| 中置信度 | `#D97706`（琥珀）边条 3px | 同左 | 行左侧边条 + 「?」点状 |
| 低置信度 | `#DC2626`（暗红）边条 3px + `#FEF3F2` 浅红底 | `#7F1D1D` 边条 + `#2A1818` 底 | 整行加警示边 + 「⚠」实心 |

## 3. 字号与文字层级

| 层级 | 字号 (mobile / desktop) | 字重 | 行高 | 用法 |
|---|---|---|---|---|
| H1 | 18 / 22 | 600 | 1.3 | 页面标题（今日 · 9月21日 周一） |
| H2 | 16 / 18 | 600 | 1.3 | 科目分组标题（语文 3/3） |
| Body | 14 / 15 | 400 | 1.5 | 任务名 |
| Body-s | 13 / 14 | 400 | 1.5 | 副信息（截止时间、置信度备注） |
| Caption | 12 / 13 | 400 | 1.4 | 时间戳、空状态说明 |
| **Number-L** | **18 / 22** | **600** | **1** | **预估 / 实际分钟数（英雄数字）** |
| Number-S | 14 / 14 | 500 | 1 | 顶部进度 N/M |

**关键约束**：
- 所有数字（分钟数、完成率、日期）一律用 `font-variant-numeric: tabular-nums`
- 数字字号 ≥ 14px，且纵向 baseline 对齐（卡片间对齐同一水平线）
- 中文字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 英文字体栈：`"SF Pro", "Inter", system-ui, sans-serif`

## 5. 组件规范

### 5.1 任务行（看板核心组件）

**单行布局**（移动端横排，桌面端可双列）：

```
┌─────────────────────────────────────────────┐
│ ▍ 语文｜完成知能P14              预估 20 分 │
│   source_span 可点开                        │
│   [● 待做] [ ] 选做  [实际：__ 分钟] [⋯]   │
└─────────────────────────────────────────────┘
```

- 左侧 `4px` 科目色条 + 8px 间距 + 任务名
- 右上角：预估分钟（tabular-nums + bold）
- 第二行：source_span 原文链接（小字、虚线下划线、点击展开）
- 第三行：状态按钮组 + 选做 checkbox + 实际分钟输入 + 更多菜单（编辑/删除）
- 行高：未做 56px，进行中 11px（带进度条），已完成 11px（轻量）

### 5.2 按钮

| 类型 | 用途 | 样式 |
|---|---|---|
| Primary | 解析 / 确认入库 | 实心 `--text-1` 底 + 白字，圆角 14 |
| Secondary | 手动添加 / 返回 | 描边 1px `--border` + `--text-1` 字 |
| Ghost | 编辑 / 删除 | 无背景 + `--text-2` 字 |
| Danger | 删除已完成（受限） | `--status-overdue` 字 + 1px 同色描边 |

- 高度统一 36px（移动端主操作 40px）
- 最小点击区 40×40（移动端）
- 加载中：Primary 按钮内显示 inline spinner，不变灰、不禁用其他按钮（避免误以为系统崩了）

### 5.3 输入框

- 高度 36px，圆角 6，1px `--border` 描边
- Focus：2px `--text-1` 外发光（不用边框变色，避免抖动）
- Error：1px `--status-overdue` 描边 + 下方 12px 红色提示文字
- 数字输入框：`type="number"` + `inputmode="numeric"`（移动端弹数字键盘），强制 `tabular-nums`

### 5.4 徽章（Badge）

| 类型 | 样式 |
|---|---|
| 科目徽章 | 主色 1px 描边 + 主色字 + 浅底色背景，圆角 4 |
| 置信度 | 高=不显示 / 中=琥珀色「?」圆形 / 低=暗红「⚠」实心方 |
| 选做 | 灰色「选」字徽章 |
| 已逾期 | 暗红底白字「逾期」徽章 |

### 5.5 进度条

- 高度 4px，圆角 2
- 已完成段：`--status-done` 实色
- 进行中段：`--status-doing` 渐变到 `--status-done`
- 剩余段：`--surface-2` 灰底
- 上方 12px 显示「已完成 N/M · 估时总计 120 分 / 已用 87 分」

## 6. 响应式断点

**移动优先（家长主要在手机上操作）**

| 断点 | 宽度 | 布局 |
|---|---|---|
| 默认 | < 640px | 单列、卡片满宽、底部 Tab Bar 固定 |
| Tablet | ≥ 640px | 单列居中 max-width 560px、Tab 顶置 |
| Desktop | ≥ 1024px | 居中 max-width 720px、可选左/右双栏（参与式仅限 ≥768px） |

**底部 Tab Bar（移动端）**：

```
┌──────┬──────┬──────┬──────┐
│ 看板  │ 解析  │ 复盘  │ 设置  │
└──────┴──────┴──────┴──────┘
```

- 高度 56px + 安全区
- 当前页：实心填充 + `--text-1`，其他：灰字 + icon
- 不出现 5 个以上 Tab（PRD 共 5 个页面，但「按日/按周列表」并入看板日历图标）

## 7. 页面详细设计

### 7.1 首页 / 今日看板

**布局（移动端自上而下）**：

1. **顶部状态条**（高 48px）
   - 左：日期 `9月21日 周一`（H1）
   - 右：进度 `N/M`（Number-S）

2. **非今日到期提醒区**（可折叠，默认展开）
   - 浅琥珀底 `#FEF3F2` 边框 + 「⚠ 本周要做」标题 + 列表
   - 示例：`周四 8:20 英语听写`（带 deadline 横线）
   - 已过期的项置灰，但仍可见

3. **进度概览**（高 80px）
   - 大进度条 + 文字「已完成 2 / 总 9 · 估时 175 分 · 已用 38 分」

4. **科目分组卡片**（语文/数学/英语依次）
   - 卡片头：科目徽章 + 完成进度 `3/3`
   - 卡片体：任务行列表
   - 选做分组：折叠在卡片底部，默认收起，点开展开

**关键交互**：
- 状态按钮：点 `待做` → `进行中`（立即发 PATCH，不需确认）→ `已完成`（如未填实际分钟，自动 focus 实际分钟输入框）
- 长按任务行：弹出菜单（编辑 / 删除 / 改为非今日 / 查看原文）
- 下拉刷新：手动触发 `GET /api/board/today`

**边界状态**：
- 今日无作业 → 显示空状态（见 §7.6）
- 凌晨 2 点访问 → 顶部日期下方加一行小字「已是凌晨 0:42，注意休息」
- 所有任务已完成 → 进度条全绿 + 「今日作业完成 ✓」+ 实际耗时汇总

### 7.2 解析页

**布局**：

1. **大文本输入区**（高度 ≥ 200px，可拉伸）
   - 占位提示「粘贴老师发的作业通知原文到这里…」
   - 右下角字符计数 `0 / 10000`

2. **操作行**（高 56px）
   - 左：`清空` Ghost 按钮
   - 右：`**解析**` Primary 按钮（高 40px）
   - 右侧：「手动添加」Secondary 按钮（**始终可见**，不依赖 AI 状态）

3. **加载状态**（解析中）
   - 按钮变 loading 态（inline spinner + 「解析中…」）
   - 下方加一行「预计 15~25 秒，请稍候」
   - 15 秒后未返回：自动显示「解析超时，请重试或手动添加」+ 重试按钮

4. **解析失败状态**
   - 错误卡片：暗红边 + 「⚠ AI 解析失败」+ 具体错误码 + 重试按钮 + 「手动添加」按钮
   - **不要丢弃已粘贴的原文**

5. **解析结果确认表格**（核心交互）
   - 表格行：勾选框 / 科目下拉 / 任务名输入 / 预估时长数字 / 是否选做 / 置信度徽章 / 删除行
   - 「低置信度」行整行警示底色 + 左侧暗红边条
   - 表格底部：「全部不勾选」按钮 + 「确认入库 N 条」Primary 按钮（数字随勾选实时变化）
   - 点击「确认入库」后跳转到今日看板，URL 带 `?from=parse&batch=N` 高亮今天新增的行

**关键交互**：
- 勾选框未勾选 → 该行不提交，但保留可编辑
- 必填字段为空 → 该行红边 + 「确认入库」禁用 + 底部提示「请补全 X 行的必填字段」
- 已解析过同一文本 → 顶部黄色提示「该文本已解析过，本次将新增 N 条，是否继续？」

### 7.3 按日 / 按周列表

**布局**：

- 顶部：日期切换器（左右箭头 + 日期 picker）+ Tab「日 / 周」
- 「日」视图：与今日看板相同组件，但无状态按钮（只读）
- 「周」视图：横向时间线 + 每天一个迷你卡片

**假期任务分组**：
- 9.22（中秋）无明确日 → 列表里 9.22 显示「假期任务」分组标题，与正常日视觉区分（虚线边框 + 「中秋假期」徽章）

### 7.4 复盘页

**布局**：

1. **时间范围选择**：「本周 / 上周」二选一 Tab + 自定义日期范围

2. **样本量提示**
   - 完成数 < 5：黄色提示卡「样本太少，复盘结果不准确（当前 3 条，建议完成 5 条以上再看）」
   - 无任何实际耗时：白底「还没有记录实际耗时，完成作业时记得填」

3. **预估 vs 实际偏差表**
   - 按「科目 × 任务类型」聚合
   - 列：科目 / 任务类型 / 预估均值 / 实际均值 / 偏差 / 样本数
   - 偏差 > +20%：暗红高亮「低估」（实际比预估久）
   - 偏差 < -20%：橙色高亮「高估」（实际比预估快）
   - 其余：默认色

4. **TOP 3 高估 / 低估**
   - 两个并排卡片，每卡列 3 条「科目 · 任务名 · 偏差百分比」
   - 点单条展开看历史明细

6. **调整建议卡**
   - 一句话建议：「数学『订正』你平均估 20 分钟，实际 35 分钟，下次建议估 35 分钟」
   - 「采纳建议」按钮 → 直接更新设置
   - 「不采纳」Ghost 按钮

### 7.5 设置页

**布局**（分组列表）：

1. **基本信息**
   - 年级：三年级（v1 固定，下拉禁用）

2. **单科基线预估**（3 个数字输入框并排）
   - 语文 / 数学 / 英语 → 默认分钟数

3. **任务类型基线**（表格，可编辑）
   - 列：任务类型 / 当前基线 / 「重置为默认」按钮

4. **作息**
   - 默认放学时间 / 晚饭时间（time picker）

5. **解析模型**（v1 固定）
   - 当前模型版本（M2 / Image-01 类文本模型）
   - 「测试 AI 连通性」按钮 → 调 `/api/health`

6. **数据**
   - 「导出全部数据」Primary 按钮 + 上次导出时间
   - 「清空所有数据」Danger 按钮（需二次确认 + 输入「确认清空」）

### 7.6 空状态 / 加载中 / 解析失败

**空状态（今日无作业）**：

```
┌─────────────────────────────────┐
│                                 │
│         📋（不是 emoji 装饰，   │
│         是单色线性 icon）       │
│                                 │
│      今天还没有作业             │
│                                 │
│  [去录入老师通知]  Primary 按钮 │
│                                 │
│  或者：手动添加一条作业         │
│                                 │
└─────────────────────────────────┘
```

- 不放插画、不放欢迎语
- 一句话一个按钮，意图明确

**加载中（看板）**：
- 9 个 skeleton 卡片（灰底 + 闪烁），不显示 spinner（家长已经熟，不需"系统在工作"提示）

**解析失败**：
- 暗红边条卡片（见 §7.2 第 4 点）
- 显示错误码（来自 PRD §6 错误码表）+ 友好说明 + 操作建议

## 8. 深色模式

**v1 提供深色模式**，通过 `prefers-color-scheme` 自动切换 + 设置页手动切换（存 localStorage）。

**实现方式**：所有色值使用 CSS 变量（见 §2），根元素加 `data-theme="dark"` 切换；**不引入构建工具**。

**关键约束**：
- 科目色在深色模式下需要重新映射（避免深底浅字看不清）：
  - 语文：`#D17A5C`（亮朱磦）
  - 数学：`#6B9DD0`（亮靛青）
  - 英语：`#85B098`（亮松烟）
- 不要"白底反色"——纯黑底会刺眼，用 `#0F1419` 这类偏蓝灰深色
- 进度条、状态色按 §2.3 表映射

## 9. 给码灵实现的 3 个前端坑（必须看）

### 坑 1：数字必须 `tabular-nums`，否则看板惨不忍睹

预估 35 分 / 实际 40 分这种，在不同任务行上下排列时，**普通字体数字宽度不等**，会导致竖列不对齐，家长扫读很费力。

**要求**：
- 所有 `<span>` 显示数字的位置：`font-variant-numeric: tabular-nums;`
- 全局 CSS 加 `font-feature-settings: "tnum";`
- 不要为数字换字体（如 Monaco / SF Mono），只换数字特性

### 坑 2：「已完成」状态必须联动实际分钟输入框，不能放任家长漏填

PRD §9 验收门槛「打覆盖率缺失率 = 0」是硬指标，但家长做完事经常忘填。状态机里要有 1 个**中间态**：

```
todo ──点状态──> doing ──点状态──> pending_actual (高亮输入框)
                                       │
                                       ▼ (填了 actual_minutes)
                                       done
                                       │
                                       ▼ (没填就提交)
                                       顶部 Toast 提醒「已标记完成，但未填实际分钟，周复盘不会计入」
```

**要求**：
- 不要弹模态框打断流程（家长讨厌被打断）
- 不要禁用按钮（家长会直接骂）
- 自动 focus 输入框 + 输入框黄色描边 + 占位文字「填一下实际分钟」
- 提供「跳过，直接完成」的 Ghost 按钮（用上面的 Toast 兜底）

### 坑 3：低置信度任务必须显眼，绝不能"温和处理"

PRD §7.3 明确要求低置信度行要家长多看一眼。如果只加一个灰色 badge，家长会**直接忽略**。

**视觉差异化要求**：

| 置信度 | 视觉 |
|---|---|
| high | 无装饰 |
| medium | 行左侧 3px 琥珀色边条 + 行尾「?」点状徽章（hover 显示「推断，建议核对原文」） |
| low | **整行**浅红底 `#FEF3F2` + 左侧 3px 暗红实心边条 + 行首「⚠」实心徽章 + 点击行展开 `source_span` 原文比对 |

**交互要求**：
- 点 `source_span` → 弹出 Popover（不是新页面），显示老师原文片段 + 高亮该任务对应的部分
- 解析页确认表格里，低置信度行的勾选框**默认不勾选**（强制家长手动勾选 = 强制过目）

### 坑 4（备用）：「手动添加」按钮必须始终可见

PRD §7.4 要求 AI 失败时不阻塞手动路径。但很多实现会等到错误才显示这个按钮，导致**家长压根不知道有这个功能**。

**要求**：解析页操作行的「手动添加」按钮**与「解析」按钮并排永久可见**，不依赖 AI 状态。失败时该按钮加 1px 暗红描边 + tooltip「AI 暂时不可用，你可以手动添加」。

## 10. 无障碍（A11y）

- 全部交互元素键盘可达（Tab 顺序合理）
- 状态按钮、置信度徽章加 `aria-label`（如「状态：待做，点击切换为进行中」）
- 颜色不是唯一信息载体：状态除颜色外，还配 shape（圆点 / 勾 / 叹号）+ 文字
- 触控目标 ≥ 40×40px
- 不依赖 hover 显示关键信息（移动端无 hover）
